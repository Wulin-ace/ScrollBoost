为 tap-strafe（TS）而生

滚轮绑定 W 做 TS 时，ScrollBoost 会把合成按键按游戏帧率摊开——一个物理刻度顶十几个点按，变向更跟手。

场景建议倍率建议间隔
日常滚动 / 网页翻页5×（默认）10ms（默认）
TS · 120Hz 显示器10–20×10–15ms
TS · 60Hz 显示器10–20×16–20ms
间隔 ≈ 游戏一帧时长时 TS 最稳。转向幅度不够 → 调大间隔；点按太稀疏 → 调小间隔。
快速上手使用方法 · 3 步完成
  1. 解压下载的 zip 到任意位置（建议 D:\ScrollBoost）。
  2. 双击 ScrollBoost.exe，程序进入系统托盘（右下角图标）。
  3. 右键托盘图标 → 打开，调整上下倍率与间隔；需要时勾选「开机自启」。
设置保存在 %LocalAppData%\ScrollBoost\settings.json，损坏或缺失会自动回退到安全默认值。

常见问题

会不会被游戏反作弊检测？

ScrollBoost 只通过 Windows 标准接口发送滚轮输入，不注入代码、不读写游戏内存、不修改游戏文件，与常规鼠标宏工具原理相同。它本身不提供任何作弊功能；是否允许使用请以各游戏规则为准。

会干扰我的宏 / 自动化软件吗？

不会。ScrollBoost 只放大真实物理滚轮事件，其他软件注入的滚轮事件一律原样放行。

如何卸载？

绿色免安装：先在设置里取消「开机自启」，然后删除程序文件夹即可。设置文件位于 %LocalAppData%\ScrollBoost\，可一并删除。

支持哪些系统？

Windows 10 1803 及以上、Windows 11，64 位。自带运行时，无需安装 .NET。
